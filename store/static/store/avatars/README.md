# Profile pictures

m1–m5 and f1–f5 are locally generated illustrated profile pictures, with varied colours and appearances. They are available to customers and administrators through the same profile page.

b1.webp was rendered from the existing bot-pfp-starry-wink.svg export found in the user's Downloads folder. It was produced by botpfp.com. The export tool on the site did not return additional files in this browser session. The remaining pictures were generated separately and are not botpfp exports.
